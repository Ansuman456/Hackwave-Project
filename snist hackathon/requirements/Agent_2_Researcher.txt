2. NON-NEGOTIABLE RESEARCH PHILOSOPHY
Follow these rules throughout the implementation.
Rule 1 — Never fabricate information
Never invent:
URLs
products
startups
GitHub repositories
features
technologies
users
limitations
citations
project names
hackathon projects
Every external fact must originate from a retrieved source.
Rule 2 — Never assume one source contains everything
A source may only provide:
nameproblemfeatures
Another source may provide:
technologyworkflowarchitecture
Merge them.
Rule 3 — Preserve evidence
Every important extracted fact should be traceable to one or more sources.
Rule 4 — Missing data is allowed
If a field cannot be verified after reasonable enrichment:
status = "unknown"
Never invent data to fill the schema.
Rule 5 — Search broadly before searching deeply
First discover candidate solutions.
Then deeply enrich the best candidates.
Do not deeply process every search result.
Rule 6 — Multiple web providers must be used
For every logical web query, execute both:
Gemini Google Search+Tavily Search
Then merge and deduplicate the results.
Do NOT normally execute only one provider.
Rule 7 — GitHub is separately queried through GitHub API
Use GitHub API for:
repository discovery
repository metadata
README
relevant files
languages
topics
repository details
Use web search as supplemental GitHub discovery when useful.
Rule 8 — Do not count duplicate references as multiple solutions
Example:
official websiteProduct Hunt pageGitHub repositoryblog articlehackathon page
may all describe one product.
Represent that as:
1 DiscoveredSolution+5 Sources
not five solutions.
Rule 9 — Research completion is based on coverage and diminishing returns
Do not use:
"10 searches means complete"
as the only criterion.
